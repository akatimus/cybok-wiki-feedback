# CyBOK 日本語 Wiki — Feedback / 報告窓口

Cyber Hiroshimaの非公式CyBOK日本語Wikiについて、不具合・翻訳の修正・使い勝手の改善提案を受け付けます。

対象サイト：[CyBOK 1.2.0 Wiki 評価版](https://wiki.cyberhiroshima.or.jp/)

## 報告する

[新しい報告を作成](https://github.com/akatimus/cybok-wiki-feedback/issues/new/choose)

GitHubアカウントでログインしてください。サイト内の報告フォームから開いた場合は、件名・本文と対象の版名・URL・管理IDなどが入力されます。内容を確認して「Submit new issue」で送信してください。

直接報告する場合は、次の情報があると確認しやすくなります。

- 参照した日本語版の版名
- 対象ページのURL、図表番号、管理ID（分かる範囲で）
- 問題の内容・再現手順・期待する表示・改善案
- 必要に応じた画面画像（端末やブラウザーの情報も参考になります）

管理IDにはDB由来のIDと校正用の表示IDがあります。Prefaceの「準備用ID」は未取込データを示します。IDが不明でも報告できます。

**この窓口の投稿と添付ファイルは公開されます。個人情報、パスワード、非公開資料は記載しないでください。** 本文や図版の転載は、確認に必要な最小限にしてください。

この窓口はCyBOK公式のサポート窓口ではありません。日本語Wikiは非公式・暫定的な評価版です。

## English

Report bugs, translation corrections and usability suggestions for Cyber Hiroshima’s unofficial CyBOK Japanese Wiki using [Issues](https://github.com/akatimus/cybok-wiki-feedback/issues/new/choose). Include the edition, URL, passage ID or figure/table number where available, and describe the problem and expected result. A GitHub account is required. Reports and attachments are public; do not include personal information, credentials or private material. This is not the official CyBOK support channel.
